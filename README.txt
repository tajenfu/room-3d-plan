Room 3D Plan / 房間 3D 配置模型

HOW TO OPEN
1. Unzip the whole file first.
2. Double-click room.html (use Chrome or Edge).
3. No internet connection is needed.

CONTROLS
- Drag furniture to move it. Drag empty floor to turn the view. Scroll to zoom.
- Arrow keys: move 1 cm (Shift: 10 cm). R: rotate. Delete: remove.
- "Add furniture" buttons add pieces. "Reset layout" starts over.
- "Saved versions": name an arrangement and Save; pick it and Load.
- To open versions someone sent you: Import, choose room-versions.json, then Load.
- To send yours back: Export, then send the downloaded room-versions.json.

Furniture sizes, alcove size and all heights are estimates.

使用方法
1. 請先解壓縮整個檔案。
2. 用 Chrome 或 Edge 雙擊開啟 room.html。
3. 不需要連上網路。

操作
- 拖曳家具可移動；拖曳空白地板可旋轉視角；滾輪縮放。
- 方向鍵移動 1 公分（加 Shift 為 10 公分）；R 旋轉；Delete 刪除。
- Add furniture：新增家具；Reset layout：還原配置。
- Saved versions：輸入名稱後按 Save 儲存；選擇後按 Load 載入。
- 開啟別人傳來的版本：按 Import 選擇 room-versions.json，再按 Load。
- 回傳自己的版本：按 Export，傳送下載的 room-versions.json。

家具尺寸、拱形壁龕尺寸及所有高度皆為估計值。
